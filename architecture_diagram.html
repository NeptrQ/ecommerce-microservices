🎯 Quick Presentation Guide (Say This to Your Professor)

1. Ingress & Gateway User calls aupp.com. NGINX Ingress forwards all requests to the API Gateway (Port 5000) as the single entrypoint.
2. Pod 1 (Auth) Contains Gateway, Register, Login, and Auth containers sharing localhost networking in one Pod.
3. Pod 2 (Business) Contains Product and Order microservices for e-commerce transactions, reached via Kubernetes Services.
4. Volume & Cloud DB Shared emptyDir volume collects logs; MongoDB Atlas cloud database safely stores all persistent data.
