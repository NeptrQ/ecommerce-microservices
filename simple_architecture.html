Simple Architecture Flow (CLD 376 Final Project)

E-Commerce Microservices System on Kubernetes

Step 1: Client

🌐 User / Postman sends request

Client accesses http://aupp.com through Fanout DNS.

⬇️
Step 2: Ingress & Entrypoint

🔀 NGINX Ingress & API Gateway (Port 5000)

The API Gateway acts as the single entrypoint (front door). It inspects the URL path and routes requests to the proper microservice.

⬇️
Step 3: Microservices in 2 Kubernetes Pods

☸️ Business Logic (6 Microservices)

📦 Pod 1 (Gateway & Auth)
• API GatewayPort 5000
• Register ServicePort 5003
• Login ServicePort 5002
• Auth ServicePort 5001
📦 Pod 2 (Business Operations)
• Product ServicePort 5005
• Order ServicePort 5004
💾 Kubernetes Shared Volume (emptyDir): Mounted at /var/log/ecommerce for shared logs
⬇️
Step 4: Cloud Database

☁️ MongoDB Atlas (ecommerce_final)

Stores user accounts (users), product catalog (products), and customer orders (orders).
